Anatomy `assertEvidenceOrSkip` is tightened so an empty `{}` no longer passes; each row must carry one of the four 7d shapes (request-id / response-body-excerpt / created-then-deleted-id-in-diff / deploy-record) or an honest `accountBoundSkipped` with a named `reason`. `aggregate([])` and null-result normalisation now report `detail: 'no checks ran'` exactly. The slug reads AMBER on criterion-e for the session-inventory ACs and GREEN on the rest; the AMBER row names the unobservable-property explicitly.
