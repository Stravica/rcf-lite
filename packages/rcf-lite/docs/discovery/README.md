# docs/discovery/

Home for engineer-facing discovery artefacts: companion write-ups to
items under `guidance/discovery/`, infographic sketches, exploratory
diagrams, and anything else that supports a DISCOVERY-stage effort
without being part of the stable umbrella docs set.

The top-level `docs/` directory is the locked docs inventory (see
`test/docs/links.test.js`). New additions there require coordinated
test updates.

Files here, under `docs/discovery/`, do not need to appear in the
locked docs set; the links test enumerates `docs/` non-recursively.

Companion home for the methodology-pack side: `guidance/discovery/`.
